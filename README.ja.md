# JMA Weather (Unofficial) — 日本語の説明

English: [README.md](README.md)

## 日本語の説明

気象庁が公開しているデータを使って、日本のどの市区町村でも天気予報・気象警報・雨の予測・台風・地震情報・津波情報・
熱中症警戒アラートを Home Assistant に表示するカスタム統合です（**非公式**。気象庁が作成・承認したものではありません）。
アカウントも API キーも不要です。

- **導入**: HACS の「カスタムリポジトリ」に `https://github.com/glockpete/ha-jma`（カテゴリ：Integration）を追加するか、
  `custom_components/jma` を手動でコピーします。必要な Home Assistant は 2026.9.0 以降です。
- **設定**: 府県予報区、市区町村の順に選びます（観測所は自動で選ばれます）。
- **オプション**: エントリーの「設定」から、主なアメダス観測所と補助の観測所の ID（5桁。全角の数字も使えます）と、テスト用アクション jma.simulate のオン・オフを変えられます。気象庁の観測所表にない ID は保存できません（観測所表を取得できないときは、入力どおりに受け付けます）。保存するとエントリーが再読み込みされます。
- **再設定（Reconfigure）**: エントリーのメニューの「再設定」で、Home Assistant の自宅の位置から2つの観測所を選び直し、地域名を更新します。市区町村とエントリー名は変わりません。オプションで入力した観測所の ID は消え、jma.simulate の設定は残ります。自宅の位置を変えたときは、エントリーが自動で再読み込みされます。
- **できること**: 天気（実況・日別・1時間ごと）、警報レベルとイベント、雨の予測（5分ごとのナウキャスト）、キキクル、台風の
  接近通知、都道府県と市区町村の震度、緊急地震速報、津波情報、熱中症警戒アラート。
- **初期状態で無効のセンサー**: `radar_frames` と `japan` は、新しく追加した地点では無効になっています。使うときは、エンティティの設定で有効にしてください。`feed_problem` は診断用のエンティティです。
- **修復（Repairs）**: 「設定 > 修復」に次の2つが表示されることがあります。地震情報に接続できないエントリー（P2P地震情報は IP アドレスごとに2接続まで）と、アメダス観測所の1つから観測が届かない場合です。原因がなくなると自動で消えます。
- **制限**: 津波予報区は東京都（東京湾内湾・伊豆諸島・小笠原諸島）、暑さ指数（WBGT）は東京でのみ使えます。ほかの地域では津波センサーは `none` の
  ままですが、全国の津波警報・大津波警報はイベントと `max_grade` 属性に出ます。
- **東京23区**: 東京23区の市区町村では、地震イベントと緊急地震速報は23区（東京都２３区）の観測点・予報区だけが対象です。
  ほかの地域（東京都の多摩・島しょを含む）は都道府県全体が対象です。
- **地震・津波情報**は P2P地震情報 から受け取ります。**これだけを頼りに避難や安全の判断をしないでください。**
- **削除**: エントリーを削除すると、台風・熱中症・津波の通知を覚えておくファイルも一緒に削除されます。ほかに残るファイルはありません（Home Assistant のデータベースにあるエンティティの履歴は、Home Assistant の通常の削除で消えます）。
- **品質スケール**: `manifest.json` では、Home Assistant がコア以外のすべての統合に割り当てる **custom** を宣言しています。Integration Quality Scale のルール（bronze〜platinum の全 54 項目）は引き続き守っており、各ルールをどこで満たしているか（または当てはまらない理由）は `custom_components/jma/quality_scale.yaml` にあり、`tests/test_quality_scale_file.py` が確認します（Home Assistant 自身はこのファイルを公式の統合でしか検証しません）。
- **出典**: 各サービスの利用規約に従って表示してください。Open-Meteo の無料 API は非営利目的に限られます。
