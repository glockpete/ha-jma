# JMA Weather (Unofficial) — 日本語の説明

English: [README.md](README.md)

## 日本語の説明

気象庁が公開しているデータを使って、日本のどの市区町村でも天気予報・気象警報・雨の予測・台風・地震情報・津波情報・
熱中症警戒アラート・噴火警戒レベルを Home Assistant に表示するカスタム統合です（**非公式**。気象庁が作成・承認したものではありません）。
アカウントも API キーも不要です。

- **導入**: HACS の「カスタムリポジトリ」に `https://github.com/glockpete/ha-jma`（カテゴリ：Integration）を追加するか、
  `custom_components/jma` を手動でコピーします。必要な Home Assistant は 2026.9.0 以降です。
- **設定**: 府県予報区、市区町村の順に選びます（観測所は自動で選ばれます）。
- **オプション**: エントリーの「設定」から、主なアメダス観測所と補助の観測所の ID（5桁。全角の数字も使えます）、火山までの距離（km。0〜500の整数、初期値は50）、テスト用アクション jma.simulate のオン・オフを変えられます。気象庁の観測所表にない ID は保存できません（観測所表を取得できないときは、入力どおりに受け付けます）。保存するとエントリーが再読み込みされます。
- **再設定（Reconfigure）**: エントリーのメニューの「再設定」で、Home Assistant の自宅の位置から2つの観測所を選び直し、地域名を更新します。市区町村とエントリー名は変わりません。オプションで入力した観測所の ID は消え、jma.simulate の設定は残ります。自宅の位置を変えたときは、エントリーが自動で再読み込みされます。
- **できること**: 天気（実況・日別・1時間ごと）、警報レベルとイベント、雨の予測（5分ごとのナウキャスト）、キキクル、台風の
  接近通知、都道府県と市区町村の震度、緊急地震速報、津波情報、熱中症警戒アラート、噴火警戒レベル。
- **ダッシュボードカード**: [JMA Weather Card (Unofficial)](https://github.com/glockpete/ha-jma-card) で、予報・警報・1時間以内の雨・雨雲レーダー・地震・津波・台風・暑さを1枚のカードに表示できます。HACS の別ダウンロード（カテゴリ：Dashboard）です。

  <a href="https://github.com/glockpete/ha-jma-card"><img src="https://raw.githubusercontent.com/glockpete/ha-jma-card/main/docs/images/full-light.png" alt="千代田区の JMA Weather Card：雨雲レーダー、現在の天気、大雨注意報、1時間以内の雨、1時間ごとの予報、週間予報、最新の地震" width="85%"></a>
- **火山**: `sensor.jma_<place>_volcano` は、気象庁の噴火警報・予報（`warning.json`）に載っている火山のうち、あなたの地点に関係するものの最高の噴火警戒レベル（1〜5。該当なしは0）を表します。関係する火山の決め方は、発表に対象市町村が書かれていればあなたの市町村がその中にあること、書かれていなければ Home Assistant の自宅からの距離がオプションの値（初期値50 km。0にすると距離による判定をしません）以内であることです。噴火警戒レベルのない火山は、気象庁の警報の区分（火口周辺危険・入山危険・居住地域厳重警戒・周辺海域警戒・活火山であることに留意）を、この統合が1〜4の数字に置き換えて表します。気象庁が定めた数字ではなく、正確な区分は属性の `kind_code` にあります。属性 `volcanoes` には、火山ごとの名前、レベル、見出し、発表時刻、気象庁のページへのリンクが最大10件入ります。`volcano_raised` と `volcano_lowered` のイベントは、関係する火山のレベルが変わったときに発生します（レベル0と1は同じ状態として扱います）。5分ごとに取得し、再起動しても同じレベルを重ねて通知しません。
- **初期状態で無効のセンサー**: `radar_frames` と `japan` は、新しく追加した地点では無効になっています。使うときは、エンティティの設定で有効にしてください。`feed_problem` は診断用のエンティティです。
- **修復（Repairs）**: 「設定 > 修復」に次の2つが表示されることがあります。地震情報に接続できないエントリー（P2P地震情報は IP アドレスごとに2接続まで）と、アメダス観測所の1つから観測が届かない場合です。原因がなくなると自動で消えます。
- **津波予報区**: 気象庁の「津波予報区に対応する沿岸の市町村対応表」（令和8年3月26日時点、66の津波予報区）にある市町村では、その津波予報区の
  階級が津波センサーの状態になります。表にない市町村（内陸、または表に載っていない湖や湾に面した市町村）では `none` のままです。津波は海に直接面していない市町村まで遡上することがあるため、
  `none` は安全を意味しません。2つの津波予報区に載っている市町村（例: 横須賀市の東京湾内湾と相模湾・三浦半島）では、`home_areas` 属性に両方が並び、階級は強いほうになります。
  東京都のうち、気象庁の表に載っていない区や多摩の市町村は、これまでどおり東京湾内湾の階級に従います。表は `scripts/build_tsunami_coast.py` で作ります。
- **暑さ指数（WBGT）**: 全国のどの府県予報区でも `sensor.jma_<場所>_wbgt` が作られます。環境省の暑さ指数予測値ファイル
  （府県ごとの `yohou_<府県>.csv`）から、Home Assistant の自宅に最も近い環境省の情報提供地点（その府県予報区の府県内、
  全国841地点）を選び、今日の予測の最高値（℃）を表示します。属性 `station`（地点番号）、`station_name`、`station_km`（自宅からの距離）で
  どの地点かが分かります。環境省の運用期間（4月第4水曜日から26週間。2026年は4月22日〜10月21日）の外では何も取得せず、
  状態は `unknown`、属性 `season` は `false` になります。出典：環境省熱中症予防情報サイト。
- **制限**: 津波センサーが `none` でも、全国の津波警報・大津波警報はイベントと `max_grade` 属性に出ます。
- **東京23区**: 東京23区の市区町村では、地震イベントと緊急地震速報は23区（東京都２３区）の観測点・予報区だけが対象です。
  ほかの地域（東京都の多摩・島しょを含む）は都道府県全体が対象です。
- **地震・津波情報**は P2P地震情報 から受け取ります。**これだけを頼りに避難や安全の判断をしないでください。**
- **削除**: エントリーを削除すると、台風・熱中症・津波・火山の通知を覚えておくファイルも一緒に削除されます。ほかに残るファイルはありません（Home Assistant のデータベースにあるエンティティの履歴は、Home Assistant の通常の削除で消えます）。
- **品質スケール**: `manifest.json` では、Home Assistant がコア以外のすべての統合に割り当てる **custom** を宣言しています。Integration Quality Scale のルール（bronze〜platinum の全 54 項目）は引き続き守っており、各ルールをどこで満たしているか（または当てはまらない理由）は `custom_components/jma/quality_scale.yaml` にあり、`tests/test_quality_scale_file.py` が確認します（Home Assistant 自身はこのファイルを公式の統合でしか検証しません）。
- **出典**: 各サービスの利用規約に従って表示してください。Open-Meteo の無料 API は非営利目的に限られます。
